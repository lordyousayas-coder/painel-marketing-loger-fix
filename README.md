# Painel de Marketing — LOGER e FIX

Painel de demandas, entregas e redes sociais do grupo, com filtros por empresa e período.

## Consulta online

[Abrir o painel](https://lordyousayas-coder.github.io/painel-marketing-loger-fix/)

Publicação pública autorizada pelo responsável em 18/11/2026. A visualização não exige conta. Links para documentos externos continuam sujeitos às permissões dos serviços de origem.

## Uso

Abra `index.html` no navegador. A página contém os dados e os recursos visuais incorporados. A pasta `Relatorios` contém somente os resumos da prévia executiva. Exportações brutas, arquivos originais das redes e comprovantes permanecem no arquivo interno da empresa. A prévia executiva está em `Previa_Diretoria_Novembro_2026.html`.

Os filtros e as alterações locais ficam no navegador de cada pessoa. Não existe sincronização de edições entre usuários. Atualizações do Notion e das redes precisam ser coletadas e publicadas em uma nova versão.

## Verificação local

Com Python instalado, execute `python -m http.server 4173 --bind 127.0.0.1` nesta pasta e abra `http://127.0.0.1:4173/`.

Nenhuma chave de API é necessária para consultar a versão incorporada. Os links para Notion, redes e documentos externos precisam de internet e das permissões dos respectivos serviços.
